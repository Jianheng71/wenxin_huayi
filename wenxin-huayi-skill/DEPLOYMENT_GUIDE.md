# 文心画意 MCP 使用说明

文心画意 MCP 服务已经由项目维护者部署。普通用户**不需要**设置 Cloudflare 子域名、打开终端、安装 Node.js、下载代码或运行部署命令；只需在支持远程 MCP 的 AI 客户端中添加服务地址。

> 重要：这个地址不能直接输入普通聊天框来安装。请在 AI 平台的 MCP、Apps、Connectors 或自定义工具设置中添加。平台必须支持自定义远程 MCP 和 Streamable HTTP；并非所有平台都支持。

## MCP 地址

```text
https://wenxin-huayi-mcp.jianhenli2-c.workers.dev/mcp
```

## 连接步骤

1. 打开你使用的 AI 客户端设置，寻找 **MCP**、**Apps / Connectors**、**开发者模式**或“自定义连接器”入口。
2. 选择添加**远程 MCP 服务**。
3. 传输方式如果需要选择，请选 **Streamable HTTP**。
4. 粘贴上面的完整地址，保存并连接。
5. 确认客户端发现以下工具：
   - `get_wenxin_huayi_guide`
   - `fetch_literary_source`
   - `prepare_illustration_prompt`
6. 在新对话中输入：

   > 以文为墨，画现乾坤！请为“雨后小院，安静，古典，带一点暮色”创作一幅图。

若没有自定义 MCP 的设置入口，该平台当前就不能直接连接这个服务。部分桌面客户端可能需要管理员开启开发者模式、本地代理，或特定账号套餐；请以平台当前的官方说明和设置页面为准。

## 平台支持情况

MCP 地址遵循 Streamable HTTP，但是否能连接由 AI 平台决定：

- **Claude**：支持远程 MCP 自定义连接器的产品入口；需要在连接器设置中添加，不是在聊天框输入地址。
- **ChatGPT**：部分账号/工作区可通过开发者模式配置自定义 MCP 应用；是否可用取决于套餐和工作区管理员设置。
- **Grok、豆包、通义千问、Coze、Kimi、腾讯元宝**：本项目无法保证其普通聊天产品支持用户自定义远程 MCP。若平台没有对应连接器入口，就不能直接添加。Grok API 可由开发者编写桥接程序调用工具，但这不等同于 Grok 聊天界面支持 MCP。

## 功能和隐私

- MCP 提供工作流程指南、白名单文学网页抓取、评分汇总和绘画提示词整理。
- AI 客户端还需要网页搜索能力来发现候选；生成图片则需要客户端自身提供图像生成工具。否则 AI 会返回可复制使用的提示词。
- 此公共服务目前没有用户认证。任何获得地址的人都能调用公开的只读工具；不要通过它提交密码、API 密钥、私人资料或机密文本。
- 服务维护者负责 Cloudflare 部署和更新。若服务地址失效，请联系项目维护者；用户无需自行重新部署。

## 项目维护者

只有需要自行托管服务的项目维护者才需要执行 Cloudflare 部署。源码、部署命令和本地测试见 [`mcp-server/README.md`](mcp-server/README.md)。
